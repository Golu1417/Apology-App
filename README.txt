A LITTLE SORRY, MY LOVE — PWA

HOW TO RUN LOCALLY:
Because service workers require localhost or HTTPS, use a local server (for example VS Code Live Server) or publish to GitHub Pages.

GITHUB PAGES:
1. Extract this ZIP.
2. Upload all files and the assets folder contents, preserving the assets/ folder, into the root of a GitHub repository.
3. In Settings > Pages choose Deploy from a branch, main, / (root), then Save.
4. Open the published HTTPS URL in Chrome.
5. To install, use Chrome menu > Install app (or Add to Home screen).

PHOTOS:
The app includes 10 photos copied from the earlier birthday app bundle.

MUSIC:
The previously user-provided audio is included at assets/jeene-laga-hoon.mp3. Use the in-app soundtrack toggle to start/pause it. Browsers may block autoplay until the user taps.

The page sequence is a single-page app, so navigation does not reload the document. The apology text is intended to be caring without pressuring someone to forgive immediately.
